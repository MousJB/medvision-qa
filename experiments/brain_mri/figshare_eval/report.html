Definitions

accuracy
Proportion of cases where predicted_label = true_label.
precision
TP / (TP + FP) for the class, one-vs-rest. Undefined if the class is never predicted.
recall
TP / (TP + FN) for the class, one-vs-rest. Undefined if the class is absent from the ground truth.
f1
2·TP / (2·TP + FP + FN) for the class. Undefined if the class is absent from both the ground truth and the predictions.
macro_f1
Unweighted mean of the per-class F1 over all declared classes. Undefined if any F1 is undefined.
sensitivity
Derived binary task: TP / (TP + FN). Undefined without a declared positive class or without a positive case.
specificity
Derived binary task: TN / (TN + FP). Undefined without a declared positive class or without a negative case.
auroc
Derived binary task, positive score = sum of the positive classes' scores; Mann-Whitney statistic, ties counted as 1/2. Undefined without scores, without a declared positive class, or if only one of the two binary classes is present.
