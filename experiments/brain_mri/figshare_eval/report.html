Définitions

accuracy
Proportion de cas dont predicted_label = true_label.
precision
TP / (TP + FP) pour la classe, un contre tous. Indéfinie si la classe n'est jamais prédite.
recall
TP / (TP + FN) pour la classe, un contre tous. Indéfini si la classe est absente des vérités terrain.
f1
2·TP / (2·TP + FP + FN) pour la classe. Indéfini si la classe est absente des vérités terrain et des prédictions.
macro_f1
Moyenne non pondérée des F1 par classe, sur toutes les classes déclarées. Indéfinie si un F1 est indéfini.
sensitivity
Tâche binaire dérivée : TP / (TP + FN). Indéfinie sans classe positive déclarée ou sans cas positif.
specificity
Tâche binaire dérivée : TN / (TN + FP). Indéfinie sans classe positive déclarée ou sans cas négatif.
auroc
Tâche binaire dérivée, score positif = somme des scores des classes positives ; statistique de Mann-Whitney, ex æquo comptés 1/2. Indéfinie sans scores, sans classe positive déclarée, ou si une seule des deux classes binaires est présente.

20. Limites de l'analyse

  • Bootstrap percentile : la couverture réelle peut être inférieure au niveau nominal pour les petits échantillons et les métriques proches de 0 ou 1.
  • Certains intervalles portent des avertissements (voir section 11).
  • 3 critères évalués sans correction de multiplicité.
  • L'outil ne peut pas prouver que les critères ont été définis avant l'analyse ; le hash de la configuration permet de le vérifier contre un historique externe (git).
  • L'alignement vérifie la cohérence des identifiants de cas, pas que ces identifiants désignent les mêmes images pour toutes les versions.
  • Les métriques portent sur la décision multiclasse (argmax) ; aucun seuil de décision alternatif n'est évalué.
