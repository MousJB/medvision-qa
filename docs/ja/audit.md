## 4. 未検証のまま残る事項

- **学習**は再実行していません（GPU、CUDA の決定性は部分的）。重みのハッシュと予測は
  コミットされたものをそのまま使っています。これらの予測からの評価は再現しました。
- **figshare の患者単位**: 同じ語幹を持つ PID の統合は仮定であり、専門家ではない者による目視
  確認に基づきます。臨床記録との照合はしていません。
- **準重複**: ラベルが異なる MRI-BT の 50 ペアのうち 26 ペアは確認していません。準重複は確認すべき
  候補であり、証拠ではありません。
- **Kaggle MRI-BT（Br35H を含む）のライセンス**: オープンではありません。バージョン管理されて
  いるのはファイル名と集計値のみであることを確認しました。
- **DeLong 法**は実装しておらず、実装したとも主張していません。AUROC の差にはペア・ブート
  ストラップを使っています。
- **多重性**: 基準は調整なしで評価しており、レポートにもそう記載しています。全体の SATISFIED には
  すべての基準が満たされる必要があります。
- **事前登録**は git の履歴（コミット `6de2a12`）でしか確認できません。ツール自身はそれを証明
  できません。
- レポートは HTTP と内容で確認しましたが、すべてのブラウザーで目視確認したわけではありません。
- Python 3.11、Linux、macOS はテストしていません。
