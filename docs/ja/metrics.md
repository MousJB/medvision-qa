# 指標と信頼区間 — v0.1

[English](../metrics.md)

実装: `src/medvision_qa/metrics.py`、`src/medvision_qa/confidence_intervals.py`。
`tests/test_metrics.py` で scikit-learn（独立した参照実装）と照合して検証しています。

## 1. 約束事

- 混同行列: 行 = 正解、列 = 予測。並びは `classes.order` の順。
- クラスごとの指標は**一対他**で計算する。TP、FP、FN は混同行列から読み取る。
- 計算できない指標は**理由を添えて未定義**とする。0 や NaN など別の値で置き換えることはない。
- 指標のキー: `accuracy`、`macro_f1`、`precision[<クラス>]`、`recall[<クラス>]`、
  `f1[<クラス>]`、`sensitivity`、`specificity`、`auroc`。

## 2. 定義と未定義になる条件

| 指標 | 定義 | 未定義になる条件 |
|---|---|---|
| `accuracy` | 正解した症例数 / 症例数 | なし（空でないファイルが保証されている） |
| `precision[c]`（適合率） | TP / (TP + FP) | `c` が一度も予測されない |
| `recall[c]`（再現率） | TP / (TP + FN) | `c` が正解ラベルに存在しない |
| `f1[c]` | 2·TP / (2·TP + FP + FN) | `c` が正解ラベルにも予測にも存在しない |
| `macro_f1` | 宣言された**全**クラスの `f1[c]` の単純平均 | いずれかの `f1[c]` が未定義（クラスを黙って除外することはない） |
| `sensitivity`（感度） | 派生二値タスクの TP / (TP + FN) | 陽性クラスがない、または陽性症例がない |
| `specificity`（特異度） | 派生二値タスクの TN / (TN + FP) | 陽性クラスがない、または陰性症例がない |
| `auroc` | 陽性スコアに対する Mann-Whitney 統計量。同順位は ½ として数える | 陽性クラスがない、スコアがない、または二値クラスの一方しか存在しない |

`f1[c]` についての注記: 式 2·TP / (2·TP + FP + FN) は、クラスが存在するのに一度も正しく
予測されない場合、適合率が未定義であっても 0 になります。これは scikit-learn の
`zero_division` 指定時と同じ結果です（テスト済み）。

派生二値タスク（[data_format.md](data_format.md#陽性クラス派生二値タスク) を参照）:
二値の予測は `predicted_label` から得て（新たな閾値は設けない）、陽性スコアは陽性クラスの
スコアの合計とします。

## 3. 信頼区間

| パラメーター | 値 |
|---|---|
| 手法 | **パーセンタイル**・ブートストラップ（両側） |
| 分位点 | `numpy.quantile(..., method="linear")` |
| リサンプリング回数 | 1000 以上（`bootstrap_resamples` パラメーター） |
| 乱数シード | 必須。生成器は `numpy.random.default_rng(seed)` |
| 単位 | `patient_id` があれば**患者**（抽出された患者の全症例を含める）、なければ**症例** |
| 症例の順序 | `case_id` でソート。結果はファイルの行順に依存しない |

これらのパラメーターはすべて `BootstrapSettings` に記録されます。

### 区間を算出しない場合

- 全標本で指標が未定義の場合。
- **1 回でも**指標が未定義になるリサンプルがある場合（例: まれなクラスが抽出に含まれない）。
  そのような抽出を除外すると区間が条件付きになり、楽観的になりすぎるため、区間は計算不可と
  し、該当する抽出の回数を示します。

### 区間に付く警告

- **幅ゼロ**: すべての抽出で指標が一定（例: accuracy = 1）。この場合、パーセンタイル・
  ブートストラップは実際の不確実性を反映しません。
- **リサンプリング単位が 30 未満**: パーセンタイル・ブートストラップの被覆確率は保証されません。
  30 という値は慣例であり、保証ではありません。

## 4. 限界

- `patient_id` がない場合、区間は症例が互いに独立であると仮定します。同じ患者の画像が複数
  含まれると、区間は**狭すぎる**ものになります（`tests/test_confidence_intervals.py` では、
  合成データの例で 2 倍を超える差を示しています）。
- パーセンタイル・ブートストラップは、標本が小さい場合や指標が 0 または 1 に近い場合、
  被覆確率が名目水準を下回ることがあります。BCa 法や Wilson 法は v0.1 では実装していません。
- 区間が広いことは、差がないことの証明にはなりません。バージョン間の比較（対応のある
  ブートストラップ）と判定については [comparison.md](comparison.md) を参照してください。
- v0.1 では多クラスのマクロ AUROC は扱わず、派生二値タスクの AUROC のみを計算します。
