# ローカル Web インターフェース — v0.1

[English](../web.md)

実装: `src/medvision_qa/web.py`、`src/medvision_qa/history.py`、テンプレート
`src/medvision_qa/templates/web_*.html.j2`。テスト: `tests/test_web.py`、`tests/test_history.py`。

```bash
pip install -e ".[web]"
python -m medvision_qa.web                # http://127.0.0.1:8000/?lang=ja（日本語）
python -m medvision_qa.web --port 8080 --data-dir D:/evaluations
```

## 1. 操作の流れ

1. **ホーム**（`/`）: アップロード用フォームと評価の履歴。右上のリンクで英語と日本語を
   切り替えられます（`?lang=ja`）。選んだ言語はすべてのページで引き継がれます。
2. `.toml` の設定ファイルと、そこで参照している CSV ファイル（最大 4 個）をアップロードします。
   CSV のファイル名は、設定ファイル内のパスと一致している必要があります。合成データのデモ用
   ファイル（日本語の設定ファイル `config.ja.toml` を含む）はホームからダウンロードできます。
3. **実行**: 検証、計算、判定（数秒）のあと、結果ページに移動します。
4. **結果**（`/evaluations/<id>`）: 総合判定と、各基準の状態および根拠。表示中の言語で
   Version Verification Record を開く・ダウンロードするためのリンクがあります。
5. **受け付けられなかった場合**（設定ファイルまたはデータが不正）: エラーの一覧を表示します
   （最大 50 件。全件は履歴に記録）。レポートは作成されず、アップロードしたファイルは
   **削除**されます。

## 2. ローカルの保存先

```
medvision_data/
├── history.sqlite          # 評価 1 件につき 1 行（完了・不受理とも）
└── runs/<id>/              # 完了した評価のみ
    ├── config.toml, *.csv  # アップロードしたファイル（バイト単位で同一）
    ├── report.html         # 英語のレポート
    └── report.ja.html      # 日本語のレポート
```

実行、フォルダー、履歴の行、レポートには同じ ID（UUID4）を使います。ファイルは変更せずに
保存するため、レポートに記載された SHA-256 はあとから検証できます。履歴にはメッセージ
（判定の根拠やエラー）をメッセージキーとパラメーターの形で保存するため、どちらの言語でも
表示できます。`medvision_data/` フォルダーは git の管理対象外です。

## 3. セキュリティ（仕様書の第 12 節）

| 対策 | 内容 |
|---|---|
| ローカルでのみ待ち受け | `127.0.0.1`。ネットワーク上で待ち受けるオプションはない |
| 外部への通信なし | 外向きのリクエスト、JavaScript、リモートリソースはいずれもない |
| ファイル名 | `^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$`、フォルダーを含めない、拡張子は `.toml` / `.csv`、重複不可 |
| サイズ | 1 ファイル 50 MB まで、CSV は最大 4 個 |
| 設定ファイル内のパス | 評価用フォルダーの中に限定（`..` と絶対パスは拒否） |
| URL 内の ID | 正規表現で UUID4 か確認したうえで、履歴から検索 |
| 読み込む内容 | CSV と TOML のみ。それ以外の方法で実行・デシリアライズすることはない |
| ヘッダー | CSP `default-src 'none'`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Cache-Control: no-store` |
| エスケープ | 利用者のテキストはすべて Jinja2 でエスケープ（HTML インジェクションでテスト済み） |
| SQL | パラメーター化したクエリ（テスト済み） |
| API ドキュメント | `/docs`、`/redoc`、`/openapi.json` は無効 |
| 言語パラメーター | `en` と `ja` のみ受け付け、それ以外の値は英語として扱う |

## 4. 制約

- 認証も CSRF 対策もない単一ユーザー向けのアプリケーションです。ネットワークに公開しないでください。
- 評価は同期処理です。計算が終わるまでページは待機します（872 症例のデモ、2,000 回の抽出で
  約 6 秒。2 つの言語のレポートを両方生成します）。
- 設定ファイルはそのままアップロードします。基準を組み立てるフォームはありません。バージョン
  管理された設定ファイルこそが、事前に定めた基準の記録になるため、意図的にそうしています。
- 画面から評価を削除する機能はありません（フォルダーと履歴の行を手動で削除してください）。
